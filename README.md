## 👀 What I'm about

I like taking a messy problem and turning it into something **people can actually use.**

Sometimes that's a web application.

Sometimes it's an ML model.

Sometimes it's figuring out how to make an AI system explain itself instead of just producing an answer.

Right now, I'm spending a lot of time learning, building, breaking things, and rebuilding them better.

What if an AI could tell you **why** a resume matches a job — not just give you a score?
