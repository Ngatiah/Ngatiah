## 🚀 Featured Work

### 🧠 [Explainable AI Resume Job Matcher](https://resumejd-75ykods9j2snaxgh5jss88.streamlit.app/)

**Making AI-powered recruitment more transparent.**

A resume-to-job matching system designed to go beyond simply saying *“this candidate matches.”*

It uses **SBERT-based semantic matching** to rank candidates and provides additional insight through **skill-gap analysis**, helping users understand *why* a candidate was matched.

**Built with:** `Python` `SBERT` `PyTorch` `Scikit-learn` `Streamlit`

🔗 [Live Demo](https://resumejd-75ykods9j2snaxgh5jss88.streamlit.app/) · [Source Code](https://github.com/Ngatiah/resume_JD.git) · [Hugging Face Model](https://huggingface.co/iwamu/bert-data-analyst-matcher)
